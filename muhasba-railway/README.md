# مولّد ورقة المحاسبة والمخالصة

تطبيق ويب عربي لرفع PDF سركيهات السيارات، وتحليل صفحات السركي بالذكاء الاصطناعي، ثم مراجعة البيانات وإنشاء ورقة محاسبة ومخالصة قابلة للطباعة.

## متغيرات التشغيل المطلوبة على Railway
- `ANTHROPIC_API_KEY`: مفتاح API من حساب Anthropic؛ مطلوب لتشغيل القراءة الذكية.
- `APP_PASSWORD`: كلمة مرور لحماية استخدام خدمة القراءة.
- `MODEL`: اختياري؛ الافتراضي كما هو محدد في `server.js`.

لا تضع مفتاح API داخل ملفات المشروع أو GitHub. أضفه في Railway Variables فقط.

## النشر
Node.js 18 أو أحدث، أمر التشغيل `npm start`، وفحص الصحة `GET /health`.
