# نظام المحاسبة والمخالصة

تطبيق ويب عربي لإدارة سراكي النقل الجماعي ومعالجة ملفات PDF الممسوحة ضوئياً باستخدام OCR على الخادم.

## التشغيل
يتم بناء التطبيق عبر Docker على Railway. يتطلب Python وTesseract OCR مع حزمة اللغة العربية.

## الوظائف
- رفع ملفات PDF للسراكي.
- استخراج نص الصفحات آلياً بالعربية والإنجليزية.
- مراجعة البيانات وتعديلها قبل اعتمادها.
- تصدير النتائج CSV وطباعة مذكرة المحاسبة والمخالصة.

> يجب مراجعة نتائج OCR للخط اليدوي قبل اعتماد أي مبالغ مالية.
